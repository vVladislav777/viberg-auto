# VIBERG AUTO

Самостоятельный демонстрационный сайт на React, TypeScript и Vite. Другие проекты в родительской папке не изменены.

## Запуск

```sh
npm install
npm run dev -- --port 5180
npm run build
```

## Структура

- `src/App.tsx` — секции страницы, услуги, фотогалерея и демо-запись.
- `src/config.ts` — изображения, услуги, цены, контакты, соцсети, адрес онлайн-записи и политика.
- `src/index.css` — стили и Tailwind CSS v4; `fonts.css` — локальный Manrope, `modal.css` — модальные окна.
- `src/components/Cinematic.tsx` — раскрытие фотографии на весь экран и затемнение при обычной прокрутке.
- `src/components/ui/` — переиспользуемые компоненты, включая BlurReveal и LiquidButton.
- `src/lib/utils.ts` — `cn` для объединения классов.
- `public/images/viberg-auto/` — предоставленные пользователем изображения.
- `components.json` — shadcn-совместимая структура с алиасом `@/components/ui`.

Каталог `components/ui` расположен внутри `src`, как принято в этом Vite-проекте. Алиас `@` указывает на `src`; такой путь позволяет добавлять компоненты через shadcn CLI без исправления их импортов. При необходимости: `npx shadcn@latest add button`. TypeScript, Tailwind и Motion уже настроены; повторная инициализация не нужна.

## Настройка студии

Контакты, социальные сети, политика и внешний адрес записи настраиваются в `src/config.ts`. Каталог и фотографии сравнения указаны в `src/catalog.ts`. Базовые цены, длительность, коэффициенты класса авто и признак демо задаются в `src/pricing.ts`. Кейсы и реальные отзывы добавляются в `src/studio-content.ts`.

Пока внешний адрес записи не указан, форма показывает предпросмотр заявки с желаемой датой. Демо не отправляет данные, не сохраняет заявку и не показывает свободные слоты.

## Изображения и анимация

Используются восемь исходных WebP, четыре новых WebP из архива VIBERG_AUTO_LFA_photos и два предоставленных PNG высокого разрешения. Главный экран и полноэкранный переход больше не используют фрагменты макетов с интерфейсом. Галерея из восьми снимков оформлена коллажем и открывается в lightbox. Материалы демонстрационные.

Кнопки Liquid Glass адаптированы из присланного компонента; установлены @radix-ui/react-slot и class-variance-authority. У SVG-фильтров уникальные идентификаторы, CSS-стекло остаётся fallback. Стандартные CTA переиспользуют этот компонент.

Для крупных заголовков используется предоставленный Rebel Type Dog, локально в public/fonts/rebel-type-dog.ttf. В файле только вес 400; браузерное усиление веса включено через font-synthesis: weight и font-weight 700–800. Описания, кнопки, цены и навигация набраны Manrope. BlurReveal использует motion/react. Остальные появления — IntersectionObserver/CSS. Полноэкранный переход работает на нативной прокрутке, на мобильных и при prefers-reduced-motion упрощён. Halftone Dots сохранён как компонент, но на странице не используется.

## Галерея и управление

Коллаж использует реальные пропорции: четыре широких кадра и четыре портретных 362×543. Все фото видны целиком, без object-fit: cover. Есть фильтры фотографий и направлений услуг. Просмотрщик поддерживает миниатюры, стрелки клавиатуры, свайп, увеличение с прокруткой и возврат к вписанному кадру. Закрытие — Escape, кнопка или область вне окна.
